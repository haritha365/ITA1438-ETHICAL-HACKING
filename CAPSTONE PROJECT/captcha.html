Adaptive Triggering Architecture
When is CAPTCHA triggered?

In conventional authentication systems, CAPTCHAs are either displayed statically on every login (ruining UX) or only after a full account lockout. SentinelShield's Adaptive Security Engine introduces intelligent intermediate friction:

  • Attempt 1–2: Normal authentication without friction for trusted users.
  • Attempt 3+: Risk score exceeds threshold (≥ 40%). CAPTCHA is injected dynamically into the login payload.
  • Automated Bots: High-speed dictionary scripts (Hydra, Burp, Python scripts) fail the CAPTCHA step immediately.
  • Successful Solution: Valid verification temporarily decrements the session's risk penalty, acknowledging human presence.
